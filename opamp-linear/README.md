# 运算放大器的线性应用（实验 7）仿真

运放型号书上没给，用近似 μA741 的行为模型（opamp.lib），±12V 供电。
`ngspice -b inv.cir`（反相比例）、`ngspice -b integ.cir`（积分）

## 表 7.1 反相比例运算（R1=10k，Rf=100k，R2=10k）
| Ui (V) | 理论 U_N | 理论 U_P | 理论 Uo | 理论 Uo/Ui | 仿真 U_N | 仿真 U_P | 仿真 Uo | 仿真 Uo/Ui |
|---|---|---|---|---|---|---|---|---|
| −0.3 | 0 | 0 | +3.0 | −10 | −0.8 mV | −0.8 mV | +2.999 | −9.997 |
| +0.3 | 0 | 0 | −3.0 | −10 | −0.8 mV | −0.8 mV | −3.001 | −10.00 |

理论：Uo = −(Rf/R1)·Ui = −10·Ui；“虚短、虚地”使 U_N = U_P = 0。
仿真里 U_N、U_P 约 −0.8 mV，是输入偏置电流（80 nA）流过 R2（10k）产生的。

## 表 7.2 积分运算（R1=10k，C=100nF，Rf=100k）
输出 Uo（示波器测量），建议的示波器挡位：
| 输入 | V/Div | 峰峰格数 | 峰峰值 | T/Div | 每周期格数 | 周期 | 频率 | 输出波形 |
|---|---|---|---|---|---|---|---|---|
| 正弦 500Hz 500mVpp | 50 mV | 3.2 | 160 mV | 500 µs | 4 | 2 ms | 500 Hz | 余弦（超前输入 90°） |
| 方波 1kHz 1Vpp | 50 mV | 5.0 | 250 mV | 250 µs | 4 | 1 ms | 1 kHz | 三角波 |

仿真值：正弦输出 159 mVpp，方波输出 252 mVpp。
理论：正弦 |Uo| = Ui / (ωR1C) = 500 mV / (2π·500·10k·100n) = 159 mV；
方波 每半周期变化 ΔUo = (0.5V / R1C) × 0.5 ms = 250 mV。
