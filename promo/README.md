# 宣传片：一次对话（粉丝自制，非官方）

成品：`promo_40s.mp4`（1080×1920 竖屏，30fps，带配乐）

暖白底色 + 衬线字（思源宋体）+ 细线条插画，讲这次对话里做过的事：
查方案 → 画角色 → 做动画 → 检查电路 → 搭 3D。

## 文件
- `index.html`：全部画面（每一幕一个函数）
- `music.py`：钢琴 + 铺底和声配乐
- `assets/`：字体子集、前两部视频的片段和截图、电路板走线数据
- `fetch_fonts.sh`：改了文案后重新下载字体子集

## 重新生成
```bash
./render_all.sh                  # 配乐 + 4 段并行渲染 + 合成
node preview.js out.png 5 13 22  # 只看几个时间点
```
