# 基尔霍夫定律实验（图 4.2.2）仿真

电路：US = 10V，R1 = 100Ω，R2 = 200Ω，R3 = 200Ω，R4 = 100Ω，以 D 点为参考地。
电流表按理想处理（内阻 0），用 ngspice 做直流工作点分析：`ngspice -b kirchhoff.cir`

## 表 4.2.2 测量数据（理论 / 仿真值）
| U_AB (V) | U_BC (V) | U_BD (V) | I1 (mA) | I2 (mA) | I3 (mA) |
|---|---|---|---|---|---|
| 4.545 | 3.636 | 5.455 | 45.45 | 27.27 | 18.18 |

另外 U_CD = 1.818 V。

## 手算过程
- R3、R4 串联：200 + 100 = 300Ω
- 再和 R2 并联：200 × 300 / (200 + 300) = 120Ω
- 总电阻：100 + 120 = 220Ω
- I1 = 10 / 220 = 45.45 mA
- U_AB = I1 × R1 = 4.545 V，U_BD = I1 × 120 = 5.455 V
- I2 = U_BD / R2 = 27.27 mA，I3 = U_BD / 300 = 18.18 mA
- U_BC = I3 × R3 = 3.636 V，U_CD = I3 × R4 = 1.818 V

## 验证
- KCL（B 点）：I1 = I2 + I3 → 45.45 = 27.27 + 18.18 ✓
- KVL（回路 A-B-D-A）：-US + U_AB + U_BD = -10 + 4.545 + 5.455 = 0 ✓
- KVL（回路 B-C-D-B）：U_BC + U_CD - U_BD = 3.636 + 1.818 - 5.455 = 0 ✓

## 实验板版本（按照片上的实验板）

板子的接法和书上的图 4.2.2 不一样，只有 3 个电阻：
Us1(+) → R1(200Ω) → I1 → 节点 B；B 分两路：I3 → R3(100Ω) → 公共线，I2 → R2(300Ω) → 公共线（回到 Us1 负极）。
也就是 R1 串联后，接 R2 和 R3 并联。电源按 10V 计算：`ngspice -b board.cir`

| R1 两端 (V) | B 到公共线 (V) | I1 (mA) | I2 (mA) | I3 (mA) |
|---|---|---|---|---|
| 7.273 | 2.727 | 36.36 | 9.09 | 27.27 |

R2、R3 两端电压相同，都是 2.727V。

手算：R2∥R3 = 300×100/400 = 75Ω，总电阻 275Ω，I1 = 10/275 = 36.36mA，
U_B = 36.36mA × 75Ω = 2.727V，I2 = 2.727/300 = 9.09mA，I3 = 2.727/100 = 27.27mA。

验证：KCL 36.36 = 9.09 + 27.27 ✓；KVL -10 + 7.273 + 2.727 = 0 ✓
