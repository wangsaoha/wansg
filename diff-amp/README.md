# 直流差动放大电路（图 6.1）仿真

ngspice：`ngspice -b dc.cir`（静态 + 直流差模/共模），`ngspice -b ac.cir`（交流单端输入）
假设：Rp 书上没标阻值，按 100Ω、滑动端在中间（调零）；晶体管用 2N3904 模型代替。
静态时两个输入端接地。

## 表 6.1 静态工作点（V）
| U_CQ1 | U_CQ2 | U_CQ3 | U_BQ1 | U_BQ2 | U_BQ3 | U_EQ1 | U_EQ2 | U_EQ3 |
|---|---|---|---|---|---|---|---|---|
| 6.40 | 6.40 | −0.68 | 0 | 0 | −7.92 | −0.65 | −0.65 | −8.59 |

T3 恒流源电流约 1.13 mA，T1、T2 各约 0.56 mA。

## 表 6.2 直流差模 / 共模（V），Ui1 = 0.2V
| | U_c1 | U_c2 | U_o双 | 放大倍数 1 | 放大倍数 2 | 双端 |
|---|---|---|---|---|---|---|
| 差模单端输入（Ui2 接地） | 0.84 | 11.95 | −11.11 | A_d1 = −27.8 | A_d2 = +27.8 | A_d双 = −55.5 |
| 共模输入（Ui1 = Ui2 = 0.2V） | 6.3964 | 6.3964 | 0 | A_c1 = −0.0019 | A_c2 = −0.0019 | A_c双 ≈ 0 |

放大倍数用相对静态值的变化量计算：A_d1 = (U_c1 − U_CQ1) / Ui = (0.84 − 6.40) / 0.2。
CMRR = |A_d1 / A_c1| ≈ 27.8 / 0.0019 ≈ 1.5×10⁴（约 83 dB）；双端输出时仿真电路完全对称，A_c双 = 0，CMRR 趋于无穷大。

注意：0.2V 已经超出线性范围，T1 几乎拿走全部电流（U_c2 接近 12V），放大倍数被压缩。
小信号（10 mV）时单端 A_d1 ≈ −49.8，双端约 −100。
